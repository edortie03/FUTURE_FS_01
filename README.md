# 🌐 Personal Portfolio Website

A modern, responsive, and visually appealing personal portfolio website built using **HTML, CSS, and Vanilla JavaScript** only.  
The design follows a **dark-mode-first**, **glassmorphism**, and **minimal UI** approach with a strong **dark blue** color theme for a clean and professional tech feel.

## ✨ Features

- 🌙 Dark-mode-first design  
- 🧊 Glassmorphism UI (frosted glass cards & blur effects)  
- 📱 Fully responsive (desktop, tablet, mobile)  
- 🎨 Modern color palette (dark blue, cyan, purple accents)  
- ⚡ Smooth animations and transitions  
- 🧠 Clean and well-structured code  
- 🚫 No frameworks — pure HTML, CSS & JavaScript  

## 🛠️ Technologies Used

- **HTML5** – semantic and accessible structure  
- **CSS3** – Flexbox, Grid, animations, glassmorphism effects  
- **JavaScript (Vanilla)** – interactivity and dynamic behavior

## 🚀 Getting Started

To run this project locally:

1. Clone the repository

```bash
   git clone https://github.com/edortie03/PORTFOLIO.git
````

2.Navigate into the project folder

```bash
   cd PORTFOLIO
```

3.Open `index.html` in your browser

No installations or dependencies required ✅
